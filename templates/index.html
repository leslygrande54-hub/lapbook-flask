🌐 HTML

Concepto

Es el lenguaje de marcado que construye la estructura de la página web. Crea títulos, párrafos, imágenes, botones y formularios.

Ejemplo

<h1>Título de mi página</h1> <p>Texto del párrafo</p>

🎨 CSS

Concepto

Se encarga del diseño y la apariencia visual. Modifica colores, fuentes, tamaños, sombras y la posición de todos los elementos HTML.

Ejemplo

h1 { color:purple; font-size:32px; }

⚡ JavaScript

Concepto

Lenguaje de programación que agrega interactividad a la página: detecta clics, valida formularios, hace cálculos y cambia contenido en tiempo real.

Ejemplo

function saludar(){ alert("¡Hola usuario!"); }

🗄️ SQL

Concepto

Lenguaje para administrar bases de datos, sirve para guardar, leer, editar y borrar la información de los usuarios del sistema web.

Ejemplo

SELECT * FROM usuarios;

🧩 Jinja2 (Flask)

Concepto

Motor de plantillas que trabaja con Flask, permite meter datos de Python dentro del HTML, usar ciclos y condicionales para páginas dinámicas.

Ejemplo

{% for nombre in lista %} <p>{{nombre}}</p> {% endfor %}

📋 Resumen General

HTML: Estructura

CSS: Diseño

JS: Interactividad

SQL: Datos / Base de Datos

Jinja2: Plantillas dinámicas en Flask


¡Todos funcionan juntos para crear una aplicación web completa!
