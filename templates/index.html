🌐 HTML

¿Qué es HTML?

HTML es el lenguaje que define la estructura de una página web. Con él creamos encabezados, párrafos, imágenes, enlaces y formularios.

<!DOCTYPE html> <html> <head> <title>Mi página</title> </head> <body> <h1>Hola mundo</h1> <p>Este es un párrafo</p> </body> </html>
Tip: HTML solo organiza el contenido; para darle color o diseño necesitamos CSS.

🎨 CSS

¿Qué es CSS?

CSS se encarga del diseño y la apariencia. Con él cambiamos colores, fuentes, tamaños, márgenes y posiciones de los elementos.

body { background: #fce4ff; font-family: Arial; } h1 { color: #6a1b9a; font-size: 28px; }
Tip: Usa clases para aplicar el mismo estilo a varios elementos sin repetir código.

⚡ JavaScript

¿Qué es JavaScript?

JavaScript agrega interactividad a la página. Sirve para responder a clics, validar formularios, mostrar mensajes y cambiar contenido dinámicamente.

function saludar() { let nombre = prompt("Escribe tu nombre"); alert("Hola " + nombre); } document.querySelector("button") .addEventListener("click", saludar);
Tip: JavaScript es el comportamiento de la página; sin él, todo sería más estático.

🗄️ SQL

¿Qué es SQL?

SQL es el lenguaje que usamos para trabajar con bases de datos. Permite guardar, buscar, modificar y eliminar información.

CREATE TABLE alumnos ( id INT PRIMARY KEY, nombre TEXT, correo TEXT ); SELECT * FROM alumnos;
Tip: En proyectos web, SQL se usa para guardar usuarios, productos, mensajes o registros de una tarea.

🧩 Jinja2

¿Qué es Jinja2?

Jinja2 es un motor de plantillas que permite combinar HTML con datos de Python. Se usa mucho con Flask para crear páginas dinámicas.

<ul> {% for alumno in alumnos %} <li>{{ alumno.nombre }}</li> {% endfor %} </ul> {% if usuario %} <p>Bienvenido {{ usuario }}</p> {% endif %}
Tip: Con Jinja2 no tienes que escribir todo el HTML a mano para cada dato que cambie.
