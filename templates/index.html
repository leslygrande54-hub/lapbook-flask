📖 LAPBOOK: FUNDAMENTOS DEL DESARROLLO WEB

🌐 HTML: ESTRUCTURA DE LA PÁGINA

¿Qué es? Lenguaje de marcado que construye la estructura: textos, imágenes, botones, listas.

<header> → Encabezado superior de la página <nav> → Menú de navegación <section> → Bloque de contenido <article> → Artículo independiente <footer> → Pie de página

Ejemplo completo:

<section> <h3>Noticias</h3> <p>Contenido de la noticia</p> </section>

🎨 CSS: ESTILOS Y DISEÑO

¿Qué es? Le da apariencia: sombras, bordes redondeados, colores degradados, posicionamiento de los elementos.

box‑shadow: sombra de los elementos border‑radius: esquinas redondeadas display: flex; → Acomodar elementos en fila background: linear‑gradient → Fondo degradado text‑decoration → Quitar/subrayar texto

⚡ JAVASCRIPT: INTERACTIVIDAD

¿Qué es? Hace que la página reaccione: cambiar colores, contar, validar formularios, mostrar mensajes personalizados.

// Contador let contador = 0 function sumar(){ contador = contador + 1 alert("El número es: "+contador) }

🗄️ SQL: BASES DE DATOS

¿Qué es? Guardamos la información de los usuarios, productos, registros para nuestra página web.

CREATE TABLE productos( id INT PRIMARY KEY, nombre TEXT, precio REAL ); SELECT nombre, precio FROM productos WHERE precio < 100;

🧩 JINJA2 + FLASK

¿Qué es? Motor de plantillas para Flask, enviamos datos desde Python al HTML, ciclos y condicionales directamente en la página.

{% for articulo in lista_articulos %} <p> {{ articulo }} </p> {% endfor %} {% if usuario %} <p>Hola {{ usuario }}</p> {% endif %}
